Image

Frees the GPU for the picture engine (ComfyUI). Stops any language model. ComfyUI itself is started below.

Language model

Loads one model into the GPU and stops ComfyUI. Loading can take a few minutes. Also closes browsers and chat apps on Predator to free memory.

Gaming

No models; Predator gets its gaming profile. Stops ComfyUI and any model.

Idle

Stops every model; nothing owns the GPU.
